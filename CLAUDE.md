# ⛔ Not the development entry point

This repository holds **runtime code and its README only**. The design docs,
decision records, and development workflow are maintained in a separate private
workspace and are intentionally not kept here.

**If you are an AI agent launched from this folder: do not start development here.**

Begin from the maintainer's documentation workspace instead. That workspace
maps this repository's local code path and drives changes from there — code
edits land in this repo, design notes stay in the private workspace. Editing
here in isolation will drift from the source-of-truth process.
